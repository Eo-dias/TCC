## 🎯 Sobre o Projeto

O **Raven** é uma Single Page Application (SPA) que apresenta uma empresa moderna e inovadora de tecnologia. O site foi desenvolvido com foco em uma experiência de usuário fluida, design profissional e interatividade.

O projeto conta com um formulário de contato funcional, permitindo que visitantes enviem mensagens diretamente para a empresa através de uma interface intuitiva.
